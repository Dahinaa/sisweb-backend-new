# sisweb-backend

SISWEB Backend project.

## Description

CRUD example based on an e-commerce shop for products.

## Technologies

- NodeJS
- Express
- TypeScript
- Morgan
- Nodemon
- Concurrently

## Available endpoints

### Root

GET http://localhost:3000/

### Products

GET http://localhost:3000/product

GET http://localhost:3000/product/:id

POST http://localhost:3000/product

PATCH http://localhost:3000/product/:id

DELETE http://localhost:3000/product
